## About the data
- 31,047 orders from January to December 2022
- Columns include Order ID, Gender, Age, Age Group, Date, Month, Status, Channel, Category, Size, Qty, Amount, ship-state and more

## What I did
- Cleaned the data and created helper columns (Age Group, Month)
- Built Pivot Tables for each analysis
- Created charts from the Pivot Tables and combined them into one dashboard
- Added Slicers (Category, Channel, Month) to make the dashboard interactive

## Analysis covered
- Sales vs Orders by month
- Men vs Women sales
- Order status (Delivered, Returned, Cancelled, Refunded)
- Top 5 states by sales
- Orders by Age Group and Gender
- Orders by sales channel

## Key insights
- Women contribute about 64% of total sales, men about 36%
- 92% of orders are delivered successfully
- Amazon is the top channel with 35% of orders, followed by Myntra (23%) and Flipkart (22%)
- Maharashtra is the top state by sales (about 2.99M), followed by Karnataka and Uttar Pradesh
- Adult women place the most orders (about 34.6% of all orders)

## Tools used
Microsoft Excel - Pivot Tables, Pivot Charts, Slicers, Dashboard design
